

# 1.介绍
中国烟草绵阳卷烟厂智慧改造项目，由于单位保密程度高，内部网络要求互不干扰，先对内部工程设备科网络进行子网划分，为该项目开辟了独立的、安全的内网环境，接口设计，通信格式设计，完成前端系统设计开发（HTML5，three.js,javasrcipt,echarts）,完成后端设计开发（堆垛机—C++，滤棒图像识别—yolov11+NAM+FRAConv，数据库—MySQL）此外特色为：1.系统与堆垛机高度交互，可实现边移动边识别支持全库AI盘库2.数字化大屏（滤棒库物料，出入库统计）3.3D库位实时显示—three.js

# 2.功能

1.数据分析（库位态势分析，日常出入库统计，物料出入情况分析）

2.二维库位展示（单盘库，全盘库，数据对比，物料统计，库位物料所在库位）

3.库位分析（出入库统计，物料入库情况，出入库日期分析，实时查看）

4.三维库位展示（库位颜色，库位余量，库位ID）
